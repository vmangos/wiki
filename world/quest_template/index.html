    Field Breakdown¶

    • entry - Primary Key. Unique quest ID.
    • patch - Primary Key. Client patch version.
    • Method - Quest method: 0 auto-complete, 1 disabled, 2 deliver (normal).
    • ZoneOrSort - Zone ID or sort index (negative for sorting).
    • MinLevel / MaxLevel - Level requirements.
    • QuestLevel - Quest difficulty level.
    • Type - Quest type (QuestInfo.dbc): 0 normal, 1 elite, 41 PvP, 62 raid, 81 dungeon.
    • RequiredClasses / RequiredRaces - Class/race masks.
    • RequiredSkill / RequiredSkillValue - Skill requirement.
    • RequiredCondition - Condition ID.
    • RepObjectiveFaction / RepObjectiveValue - Reputation goal.
    • RequiredMinRepFaction / RequiredMinRepValue - Minimum reputation requirement.
    • RequiredMaxRepFaction / RequiredMaxRepValue - Maximum reputation (for hostile quests).
    • SuggestedPlayers - Suggested group size.
    • LimitTime - Time limit (seconds).
    • QuestFlags - Flags.
    • SpecialFlags - Special flags (e.g., 1 repeatable, 2 exploration/event).
    • PrevQuestId / NextQuestId - Quest chain links.
    • ExclusiveGroup - Shared group (only one quest in group can be active).
    • BreadcrumbForQuestId - Lead-in quest pointing at the target quest X given here. This quest is acceptable only while X itself is takeable (it hides behind X's own prerequisites); while this breadcrumb is active/incomplete, X cannot be accepted.
    • NextQuestInChain - Next quest in chain.
    • SrcItemId / SrcItemCount - Source item required.
    • SrcSpell - Spell cast to start quest.
    • Title / Details / Objectives - Quest text.
    • OfferRewardText - Text shown when completing.
    • RequestItemsText - Text shown when turning in.
    • EndText - Final dialogue.
    • ObjectiveText1-4 - Objective descriptions.
    • ReqItemId1-4 / ReqItemCount1-4 - Required items.
    • ReqSourceId1-4 / ReqSourceCount1-4 - Required source items.
    • ReqCreatureOrGOId1-4 / ReqCreatureOrGOCount1-4 - Required kills/interactions.
    • ReqSpellCast1-4 - Required spell casts.
    • RewChoiceItemId1-6 / RewChoiceItemCount1-6 - Choice rewards.
    • RewItemId1-4 / RewItemCount1-4 - Fixed item rewards.
    • RewRepFaction1-5 / RewRepValue1-5 - Reputation rewards.
    • RewRepSpilloverMask - Bitmask over RewRepFaction1..5 indexes (bit 0 = faction 1 ... bit 4 = faction 5). A set bit disables reputation spillover from that reward faction.
    • RewXP - Experience reward.
    • RewOrReqMoney - Money reward (or cost).
    • RewMoneyMaxLevel - Max-level money reward.
    • RewSpell - Spell reward (learn spell).
    • RewSpellCast - Spell cast on completion.
    • RewMailTemplateId / RewMailDelaySecs / RewMailMoney - Mail reward.
    • PointMapId / PointX / PointY / PointOpt - Map POI for quest objective.
    • DetailsEmote1-4 / DetailsEmoteDelay1-4 - Emotes during quest details.
    • IncompleteEmote / CompleteEmote - Emotes for incomplete/complete state.
    • OfferRewardEmote1-4 / OfferRewardEmoteDelay1-4 - Emotes during reward offering.
    • StartScript - Script ID for quest start.
    • CompleteScript - Script ID for quest completion.

    Flag Bitmasks¶

    Values from src/game/QuestDef.h.

    QuestFlags (client-visible)¶

    Flag Name Effect
    0x00000000 NONE no flags
    0x00000001 STAY_ALIVE (not used currently)
    0x00000002 PARTY_ACCEPT whole party gets a confirmation popup to accept
    0x00000004 EXPLORATION (not used currently)
    0x00000008 SHARABLE quest can be shared with party members (CanShareQuest)
    0x00000010 - reserved / unused
    0x00000020 EPIC (unused)
    0x00000040 RAID (unused)
    0x00000100 UNK2 -
    0x00000200 HIDDEN_REWARDS rewards hidden in the offer window & quest log
    0x00000400 AUTO_REWARDED auto-completes; never appears in the quest log

    SpecialFlags (server-side)¶

    Set with |value syntax in DB:

    Value Name Effect
    1 REPEATABLE quest can be repeated (resets on completion)
    2 EXPLORATION_OR_EVENT completes via area exploration, the QUEST_EXPLORED script command, or the quest-complete spell effect

    Values 0x008+ (DELIVER, SPEAKTO, KILL_OR_CAST, TIMED) are internal flags computed by the core from your objective columns; never set them manually.

    Interaction With Other Systems¶

    • Timed quests: LimitTime > 0 sets the countdown (internal TIMED flag).
    • Exploration completion pairs SpecialFlags = 2 with an areatrigger id in areatrigger_involvedrelation.
    • Repeatable daily/weekly rotation is driven by game events + QUEST_SPECIAL_FLAG_REPEATABLE.
    • Reward visibility for surprise rewards uses HIDDEN_REWARDS.
