    Field Breakdown¶

    Identity & Text¶

    • entry - Spell ID (Spell.dbc id).
    • build - Client build this row applies to.
    • name, nameSubtext, description, auraDescription - Display text (name, subtext/rank line, tooltip body, aura tooltip). Only name and nameSubtext are read by the core; description / auraDescription are client-DBC/informational columns.
    • nameFlags, nameSubtextFlags, descriptionFlags, auraDescriptionFlags - Locale mask for the Aura Description (tooltip) text; not read by core.

    Identity Extras¶

    • castUI - DBC passthrough column; not read by core.

    Classification¶

    • school - Base magic school: 0 physical, 1 holy, 2 fire, 3 nature, 4 frost, 5 shadow, 6 arcane.
    • category - Category id; spells sharing a category share cooldowns (e.g. all Hearthstone-like items).
    • dispel - Dispel type (enum DispelType, SpellDefines.h):

    0 NONE
    1 MAGIC
    2 CURSE
    3 DISEASE
    4 POISON
    5 STEALTH
    6 INVISIBILITY
    7 ALL
    8 SPE_NPC_ONLY
    9 ENRAGE
    10 ZG_TICKET

    Attribute Flags¶

    Bitmask columns; every bit is defined as SPELL_ATTR_* in src/game/Spells/SpellDefines.h.

    attributes¶

    Flag Name Notes
    0x00000001 PROC_FAILURE_BURNS_CHARGE
    0x00000002 USES_RANGED_SLOT All ranged abilites have this flag
    0x00000004 ON_NEXT_SWING_NO_DAMAGE
    0x00000008 NEED_EXOTIC_AMMO Vanilla only attribute removed in TBC
    0x00000010 IS_ABILITY Client puts 'ability' instead of 'spell' in game strings for these spells
    0x00000020 IS_TRADESKILL Trade spells, will be added by client to a sublist of profession spell
    0x00000040 PASSIVE
    0x00000080 DO_NOT_DISPLAY Spells with this attribute are not visible in spellbook or aura bar
    0x00000100 DO_NOT_LOG This attributes controls whether spell appears in combat logs
    0x00000200 HELD_ITEM_ONLY Client automatically selects item from mainhand slot as a cast target
    0x00000400 ON_NEXT_SWING
    0x00000800 WEARER_CASTS_PROC_TRIGGER
    0x00001000 DAYTIME_ONLY Only useable at daytime, not set in 2.4.2
    0x00002000 NIGHT_ONLY Only useable at night, not set in 2.4.2
    0x00004000 ONLY_INDOORS Only useable indoors, not set in 2.4.2
    0x00008000 ONLY_OUTDOORS Only useable outdoors
    0x00010000 NOT_SHAPESHIFT Not while shapeshifted
    0x00020000 ONLY_STEALTHED Must be in stealth
    0x00040000 DO_NOT_SHEATH Client won't hide unit weapons in sheath on cast/channel
    0x00080000 SCALES_WITH_CREATURE_LEVEL Spell damage depends on caster level
    0x00100000 CANCELS_AUTO_ATTACK_COMBAT Stop attack after use this spell (and not begin attack if use)

    0x00400000 TRACK_TARGET_IN_CAST_PLAYER_ONLY SetTrackingTarget
    0x00800000 ALLOW_CAST_WHILE_DEAD Castable while dead
    0x01000000 ALLOW_WHILE_MOUNTED Castable while mounted
    0x02000000 COOLDOWN_ON_EVENT Activate and start cooldown after aura fade or remove summoned creature or go
    0x04000000 AURA_IS_DEBUFF Almost all negative spells have it
    0x08000000 ALLOW_WHILE_SITTING Castable while sitting
    0x10000000 NOT_IN_COMBAT_ONLY_PEACEFUL Cannot be used in combat
    0x20000000 NO_IMMUNITIES Unaffected by invulnerability
    0x40000000 HEARTBEAT_RESIST Chance for spell effects to break early (heartbeat resist)
    0x80000000 NO_AURA_CANCEL Positive aura can't be canceled

    Stances & Target Restrictions¶

    • stances / stancesNot - Shapeshift forms required / forbidden (bitmask).
    • targets - Extra target mask (e.g. corpse targets).
    • targetCreatureType - Only affects creatures of this type (CreatureTypeMask).
    • requiresSpellFocus - Requires a nearby spell-focus object (gameobject_template type 8 objects).
    • casterAuraState / targetAuraState - Caster/victim must have this aura state.

    Timers & Cooldowns¶

    • castingTimeIndex - Row in CastTime.dbc (cast duration).
    • recoveryTime - Cooldown (ms) before the same spell may be recast.
    • categoryRecoveryTime - Cooldown applied to the whole category.
    • interruptFlags / auraInterruptFlags / channelInterruptFlags - What breaks the cast / removes auras / stops channeling (movement, damage, ...).
    • startRecoveryCategory / startRecoveryTime - Global cooldown category and time applied when the cast starts.
    • maxAffectedTargets - Hard cap on number of targets hit.

    Procs¶

    • procFlags - Event mask that can trigger the proc (melee hit, spell cast, ...).
    • procChance - Proc frequency (PPM handling and flat % values).
    • procCharges - Charges consumed when the proc fires.

    Levels & Scaling¶

    • maxLevel - Highest character level that may learn/receive it.
    • baseLevel - Level of the base rank.
    • spellLevel - Required level shown on tooltips / used in downranking math.

    Power Costs¶

    • durationIndex - Row in SpellDuration.dbc.
    • powerType - Power consumed (enum Powers, SharedDefines.h): 0 Mana, 1 Rage, 2 Focus, 3 Energy, 4 Happiness (0xFFFFFFFE Health).
    • manaCost - Flat cost percentage/value depending on power type.
    • manCostPerLevel - Additional cost per caster level.
    • manaPerSecond / manaPerSecondPerLevel - Upkeep costs while active/channeling.
    • manaCostPercentage - Cost as % of total mana.

    Range, Speed & Stacking¶

    • rangeIndex - Row in SpellRange.dbc (max/min range).
    • speed - Projectile travel speed (yards/sec); 0 = instant.
    • stackAmount - Max stacks of the produced aura.
    • modelNextSpell - DBC passthrough field; not used by the core.

    Reagents, Totems & Equipment Requirements¶

    • totem1 / totem2 - Required totem items (item_template.entry; shaman spells).
    • reagent1, reagent2, reagent3, reagent4, reagent5, reagent6, reagent7, reagent8 - Consumed reagent item entries. (see item_template.entry)
    • reagentCount1, reagentCount2, reagentCount3, reagentCount4, reagentCount5, reagentCount6, reagentCount7, reagentCount8 - Amount for the matching reagent.
    • equippedItemClass / equippedItemSubClassMask / equippedItemInventoryTypeMask - Weapon/armor requirements for combat procs (-1 = any).

    Effects 1-3¶

    Each effect slot has the same set of columns:

    • effect1 / effect2 / effect3 - Effect type (SPELL_EFFECT_*), see the Effect Types table below.
    • effectDieSides1 / effectDieSides2 / effectDieSides3 - Random dice portion of the magnitude.
    • effectBaseDice1 / effectBaseDice2 / effectBaseDice3 - Base die count.
    • effectDicePerLevel1 / effectDicePerLevel2 / effectDicePerLevel3 - Dice added per caster level.
    • effectRealPointsPerLevel1 / effectRealPointsPerLevel2 / effectRealPointsPerLevel3 - Flat points added per caster level.
    • effectBasePoints1 / effectBasePoints2 / effectBasePoints3 - Base value (dice roll is added to this).
    • effectBonusCoefficient1 / effectBonusCoefficient2 / effectBonusCoefficient3 - Spell-power coefficient.
    • effectMechanic1 / effectMechanic2 / effectMechanic3 - Mechanic applied by this effect.
    • effectImplicitTargetA1, effectImplicitTargetA2, effectImplicitTargetA3, effectImplicitTargetB1, effectImplicitTargetB2, effectImplicitTargetB3 - Target selection rules (TARGET_* ids from Spell.dbc).
    • effectRadiusIndex1 / effectRadiusIndex2 / effectRadiusIndex3 - Row in SpellRadius.dbc.
    • effectApplyAuraName1 / effectApplyAuraName2 / effectApplyAuraName3 - Aura applied by the effect (SPELL_AURA_*).
    • effectAmplitude1 / effectAmplitude2 / effectAmplitude3 - Tick interval for periodic auras (ms).
    • effectMultipleValue1 / effectMultipleValue2 / effectMultipleValue3 - Multiplier for combo-point/hot scaling values.
    • effectChainTarget1 / effectChainTarget2 / effectChainTarget3 - Additional targets hit by chaining.
    • effectItemType1 / effectItemType2 / effectItemType3 - Item created (CREATE_ITEM) or loot item (for some effects).
    • effectMiscValue1 / effectMiscValue2 / effectMiscValue3 - Generic per-effect payload (faction id, aura slot, school...).
    • effectTriggerSpell1 / effectTriggerSpell2 / effectTriggerSpell3 - Spell triggered/taught/applied by this effect (spell_template.entry).
    • effectPointsPerComboPoint1 / effectPointsPerComboPoint2 / effectPointsPerComboPoint3 - Value added per combo point.

    Visuals, Icons & Family¶

    • spellVisual1 / spellVisual2 - Cast visual ids (SpellVisual.dbc); spellVisual2 is skipped by the core (not used).
    • spellIconId / activeIconId - Tooltip/action icons.
    • spellPriority - Aura display priority.
    • spellFamilyName / spellFamilyFlags - Class/family identification used by procs and talent interactions.
    • minTargetLevel / maxTargetLevel - Target level restrictions.
    • dmgClass - Damage class: 0 none, 1 magic, 2 melee, 3 ranged.
    • preventionType - What blocks casting: 0 none, 1 Silence, 2 Pacify (SPELL_PREVENTION_TYPE_*).
    • stanceBarOrder - Position in the shapeshift bar (DBC passthrough; not read by the core).

    Misc & Server Fields¶

    • dmgMultiplier1, dmgMultiplier2, dmgMultiplier3 - Per-effect damage multiplier (e.g. AoE falloff).
    • minFactionId / minReputation - Reputation requirement for the spell to work (DBC passthrough; not read by the core).
    • requiredAuraVision - Caster needs an aura allowing them to see stealth/invisible targets of this kind (DBC passthrough; not read by the core).
    • customFlags - Server-side flags loaded into SpellEntry::Custom (SPELL_CUSTOM_*, SpellDefines.h: allow stacking between casters, fixed damage, ignore armor, separate aura per caster...).
    • script_name - C++ spell script binding (Scripts Library); also referenced from spell_script_target setups.

    Proc Behaviour¶

    • procFlags: event mask (melee/ranged swing or ability dealt & taken, spell cast, kill, heartbeat tick...), bits defined as PROC_FLAG_* in src/game/Spells/SpellDefines.h.
    • procChance, procCharges: frequency & charge consumption.
    • Detailed triggers: spell_proc_event.
